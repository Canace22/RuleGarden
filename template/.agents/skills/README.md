# Skills 索引

AI agent 在对应场景自动加载。新增、改名或删除 skill 后，同步更新这张表。

## 共享 skill

来自 [RuleGarden](https://github.com/Canace22/RuleGarden)。同步时会被覆盖，不要在项目里直接改；要定制就另写一个项目 skill。

| Skill | 什么时候用 |
|---|---|
| `skill-harvest` | 做完有套路或踩过坑的任务后，判断是否值得沉淀成 skill；发现规则过时或矛盾时提议修剪 |
| `safe-change-workflow` | 改代码前后走一遍：定向搜索 → 看懂相关代码 → 最小化改动 → 列 3-5 条 case 预期 |
| `pre-commit-secrets` | 提交 / push 前扫描密钥、token、`.env`、私钥、数据库连接串 |
| `mermaid-verify` | 画完 Mermaid 图后自检语法能否渲染、暗色主题下是否清晰 |
| `human-readable-docs` | 写、改、审 README 等给人看的文档，切到“第一次来的人”的视角 |
